## September 18th, 2026

### Objectives
- Finish project proposal

### Record
Today, we finished our project proposal which gave insight into our subsystems and requirements. We decided that we'll be using React for the user interface. The dispenser will be battery powered and use ToF sensors to detect the height of the pads and tampons. Our tolerance analysis is for the ToF sensors since that is how we will obtain our count information. Roughly, a pad box has the height of 1" and a tampon has a diameter of 5/8", so this will be used to approximate the item count in each stack. This information will be sent to the microcontroller, which will then send it the backend subsystem over Wi-Fi to process the data. Status LEDs will indicate whether the device is working properly.
